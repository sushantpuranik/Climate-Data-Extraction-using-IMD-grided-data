Easy Data Extractor App
Need to pull weather, climate, or scientific data for specific locations from large grid files? This web tool makes it effortless—no coding required!

How It Works:
Select Your Parameters: Pick the specific data parameters you want to extract using a user-friendly dropdown menu.

Upload Your Files: Drop your gridded data file (or multiple files) directly into the app.

Choose Your Location:

Type in a single coordinate (latitude and longitude) manually, OR

Upload a simple CSV file containing a list of location IDs, latitudes, and longitudes.

Download: Click "Generate CSV," and your extracted data downloads instantly to your computer!
