Streamlit ready python code with the help of which user can extract single or multiple location data from grided data files.
User get option to select parameter for extraction. User need to upload grided file/ files and the provide single location detail manually 
or can upload csv containing location id, lat, lon details.
Once input (grd files and desired coordinates) are provided to the code simply click on generate csv that's it !!
CSV gets downloaded on the system.
